# Syllabus Drill

Paste or upload a course syllabus and Claude writes a practice quiz from it, with instant feedback, explanations, and a "drill my missed topics" loop.

- **Live version (claude.ai Artifact):** https://claude.ai/artifact/PGLhsQuavxUiEFAuqNdsG7. It's private, so open it while signed in.
- **Local version:** open `index.html` in a browser. The example quiz works offline. Generating new quizzes currently needs the claude.ai Artifact runtime (`window.claude.use("sample")`). See the issues for a local API-key mode.

## Files
- `syllabus-drill.html`: the Artifact source, as published.
- `index.html`: the same page wrapped as a standalone HTML document.
